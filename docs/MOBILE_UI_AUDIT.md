# Mobile UI Audit
All screens are technically responsive via Tailwind CSS, but some components rely on desktop-first paradigms (wide tables, complex multi-column grids).
- **MOBILE_READY:** Login, Profile, Dashboard Shell.
- **MOBILE_ADAPTABLE:** Unified Request Center, Parking Hub (needs vertical stacking for lists).
- **DESKTOP_FIRST:** Audit Logs, Admin Tables (need card-based mobile views).
